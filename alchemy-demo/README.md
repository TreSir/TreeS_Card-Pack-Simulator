# Arcana · 炼金试局

讨论中“抽卡、阵列、炼金、带出”循环的独立可玩原型。所有程序和所需塔罗 JPG 均在本目录；没有修改原项目的页面、卡池、脚本或存档。

## 启动

需要 Node.js 20+，运行游戏无需安装依赖：

```powershell
cd D:\Projects\CARD\t1\t1\alchemy-demo
npm start
```

打开 <http://127.0.0.1:4175/>。换端口：`npm start -- --port 4176`。

也可直接打开本目录 `index.html` 试玩，但建议使用服务器，浏览器对 file 页面存档的支持各有差异。

## 当前规则

- 三关，目标分依次为 210 / 330 / 400；后两关分别削弱倍率增益、额外发动收益。首通解锁下一关，也可以重玩旧关。
- 每局消耗一张仓库牌作起手；可以选择免费愚者，避免库存耗尽后无法继续。初始提供五张仓库牌便于尝试。
- 每局最多开六包，每包五张。最多一张入阵、另一张入包，两个选择都可跳过。选择在发动前可撤回。
- 阵列最多五张。满阵时点击目标阵位替换；用左右箭头调整顺序，包括本包待入阵卡。
- 每包只能发动一次，从左到右结算，分数累计。触发牌无法复制触发牌，避免无限循环。计分逐步取整。
- 随身背包最多三张。点击两张已有材料可预览炼金结果；三张不同标签可合成贤者之石。可移除一张牌腾出背包位置，也可将牌直接上阵；阵满时选择替换位置，旧阵列牌消耗。
- 本包待入包的牌在确认发动后正式存入。合成结果留在背包里，可选中后直接投入当前阵列；上阵为单向操作，无法再带出。
- 随时可以结束；如果本包尚未发动，“发动并结束”会先提交选择并计分，再判定过关。第六包后不能继续开包，但仍可炼金。
- 累计分达到目标才过关。无论是否过关，都可从背包里按当前上限选择带回：默认一张，每张在阵的旅人增加一个名额，最多三张；同名牌按实体数量入库。其余局内牌消耗。
- 卡包从统一基础池抽取，同包同名牌最多两张，每包至少有一张直接产分牌。合成专属牌通过炼金获得。没有选包或选方向的额外流程。

浏览器存档键：`arcana-alchemy-demo-v1`。仓库、解锁、最高分、正在进行的牌局、当前抽牌结果都会保存。刷新不会换包。首页有重置试玩存档按钮；不会影响原项目。

## 调整玩法

- `data.js`：基础牌、合成牌、效果数值、抽取权重、关卡目标、Boss、固定配方。
- `engine.js`：抽取、分配、排序、计分、合成、库存消耗和带出规则。
- `app.js`：交互、计分演出、浏览器存档。
- `style.css`：独立的桌面与移动布局。
- `assets/`：从原项目复制的十张塔罗 JPG；继承原项目素材的权利限制。

v0.2 增加背包上阵与动态带出名额。保留 v0.1 存档格式，旧进度无需重置。

这是验证选择手感的试玩版，数值仅作试玩起点。普通与合成牌共十六种，没有额外战斗、地图或撤离点系统。
